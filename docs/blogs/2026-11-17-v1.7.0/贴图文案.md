## 一、正文文案（直接复制，约 300 字）

<!-- COPY_START -->

晚上客厅灯关了，电视画面是暗的。观看时间一到，自动弹出的学习页却是一整屏浅底——那一下光线跳得厉害。

给「学后看 · 电视英语」加了深浅两套配色（v1.7.0）。家长配置 → 系统与记录 → 界面主题，遥控器按确认键在自动 / 浅色 / 深色之间切换，选完立即生效。默认自动，跟着电视系统主题走；系统不提供深色状态时会停在浅色，手动选深色就行。

首页、词卡、答题反馈、完成页、探险地图、学习记录、家长配置和 PIN 页都跟着变。改的是界面配色，不是调屏幕亮度，学习和观看的规则一个没改。

目前只在一台小米 MiTV-MFTR0 / Android 14 上实机验过，其他固件还没测。v1.7.0 已发布，覆盖安装即可。

学后看 · 电视英语，先学一轮英语，再看一会儿电视。

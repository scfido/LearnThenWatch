## 约定

- 文章事实口径以 `CHANGELOG.md`、`docs/VALIDATION.md` 为准；已知限制照直写，不写绝对化承诺。
- 对外品牌名统一「学后看 · 电视英语」，配固定句「先学一轮英语，再看一会儿电视」；系统无障碍服务名「学后看 · 观看管控」按应用实际名称原样保留。
- 首篇（2026-11-09）已发布，归档稿保持发布时原样，不随品牌口径调整。
- 图片是应用界面或演示数据，不含真实学习记录、家长密码和设备私有信息。
- 本目录和 `.workbuddy/` 都会随仓库提交：不要放密钥、PIN、设备数据或本机绝对路径。
- 公众号正文外链不可点，GitHub 地址保持纯文本。

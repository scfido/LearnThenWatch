## 约定

- 文章事实口径以 `CHANGELOG.md`、`docs/VALIDATION.md` 为准；已知限制照直写，不写绝对化承诺。
- 「贴图」与「文章」是两种不同形态：贴图为竖版 3:4 图组（1–9 张）＋短文案，首图需大字标题，不做长文排版与横版封面；归档时按形态分别说明。
- 对外品牌名统一「学后看 · 电视英语」，配固定句「先学一轮英语，再看一会儿电视」；系统无障碍服务名「电视英语 · 观看管控」按应用实际名称原样保留。
- 首篇（2026-11-09）已发布，功能说明和历史截图保留发布时版本；文字中的产品名及安装名称随当前命名统一。旧版本系统中可能仍显示「学后看 · 观看管控」。
- 图片是应用界面或演示数据，不含真实学习记录、家长密码和设备私有信息。
- 本目录和 `.workbuddy/` 都会随仓库提交：不要放密钥、PIN、设备数据或本机绝对路径。
- 公众号正文外链不可点，GitHub 地址保持纯文本。

# 安装学后看

选择[Agent 安装](#方式一agent-安装)或[手动 U 盘安装](#方式二手动-u-盘安装)即可。电视或盒子需要支持 Android APK 安装，系统版本为 Android 8.0 及以上。

## 安装前先确认

1. 到「关于本机」查看 Android 版本，确认是 Android 8.0 或更高版本。厂商系统的版本号与 Android 版本号可能不同。
2. 确认电视、盒子或投影仪允许安装 APK。
3. 需要管理观看时间时，电视上应安装云视听小电视，并能开启「学后看 · 观看管控」无障碍服务。

已测试的设备与系统版本见[兼容性说明](VALIDATION.md)。

## 方式一：Agent 安装

适合希望让 AI 帮忙完成电脑操作的家长。准备一台电脑，让电脑和电视连接家里的同一个网络。

### 1. 选择电脑上的 Agent

可以使用下面任意一种工具：

- 国内：[TRAE](https://www.trae.cn/)、[腾讯 WorkBuddy](https://www.workbuddy.cn/)。
- 国外：[Codex](https://openai.com/codex/)、[Claude Code](https://claude.com/product/claude-code)、[Cursor Agent](https://cursor.com/downloads)。

使用在自己电脑上运行的版本，开启它的智能体 / Agent 模式，并允许它执行电脑命令。连接和安装由 Agent 操作，家长负责电视上的开关、配对和授权确认。

### 2. 用遥控器开启电视 ADB

ADB 是让电脑连接电视的调试功能。先打开电视「设置」，按品牌查找下面的入口：

| 电视品牌 | 常见开启位置 |
| --- | --- |
| **小米 / Redmi** | 「设置 → 关于」，在「产品型号」上连续按确认键 7 次；再到「账号与安全」或开发者选项中打开「ADB 调试」 |
| **TCL / 雷鸟** | 「设置 / 系统设置 → 关于本机 → 本机信息」；部分机型在该页依次按「上、下、左、右」，出现「更多」后查找 ADB 开关 |
| **索尼**（Android TV / Google TV） | 「设置 → 系统 / 设备偏好设置 → 关于」，在「内部版本号 / 版本号」上连续确认 7 次，再进入开发者选项 |
| **海信 / Vidda**（Android 机型） | 从「设置 → 关于 / 本机信息」查找开发者选项；部分机型在「关于」页面连续按确认键 7 次后出现，随后开启 USB 调试 |
| **创维 / 酷开** | 部分机型在「设置 → 关于电视」连续确认「软件版本号」7 次，再进入开发者选项开启 USB 调试 |
| **康佳 / 长虹** | 先在「设置 → 系统 / 关于 / 本机信息」查找开发者选项，具体开启方式按电视完整型号确认 |
| **OPPO（含 S1）** | 在「设置 → 系统 → 关于本机 → 设备型号」按「上、上、右、右」再确认，然后到开发者选项打开 USB 调试；IP 在已连接网络页面底部 |
| **海尔 / 模卡** | 部分机型按机身信号源键，再用遥控器按「左、左、上、右」进入工厂菜单，只打开 ADB 调试；不要更改其他项目或选择工厂复位 |

菜单会随型号和系统更新变化。找不到时，把「关于电视」中的完整型号发给 Agent，按该型号核对入口，不需要修改其他工程设置。

进入开发者选项后，查看是否有「ADB 调试」「USB 调试」「网络调试」或「无线调试」开关。要通过家里网络连接，电视需要开放网络 ADB 或无线调试；只打开 USB 调试不一定能无线连接。

入口参考：[小米官方说明](https://www.mi.com/ph/support/article/KA-06513/)、[索尼说明](https://pro.sony/s3/2019/07/25131224/TEOS-Pro-BRAVIA-Android-7-Installation-User-manual-1.0.pdf)，以及 QuickTVUI 的 [TCL](https://www.quicktvui.com/zh-CN/guide/device/tcl.html)、[海信](https://www.quicktvui.com/zh-CN/guide/device/hisense.html)、[创维](https://www.quicktvui.com/zh-CN/guide/device/skyworth.html)指引。

### 3. 允许连接或使用配对码

**如果电视提供普通网络 ADB：**

1. 在「设置 → 网络」或「关于」中找到电视 IP 地址，例如 `192.168.1.100`。
2. 如果页面还显示端口，把端口一起记下；部分机型使用 `5555`，由 Agent 按实际情况连接。
3. Agent 发起连接后，电视可能弹出「允许 USB 调试」或「允许网络调试」，用遥控器选「允许」。

**如果电视有「无线调试 → 使用配对码配对」：**

1. 打开该页面，让配对窗口保持显示。
2. 把页面上的「配对地址和端口」及临时配对码提供给自己电脑上的 Agent。
3. 配对完成后，回到无线调试主页面，再把「连接地址和端口」提供给 Agent。

配对端口和连接端口可能不同，配对成功后还需要连接。配对码会过期，重新打开页面后请提供新码；不要把配对码或家长密码发到公开的问题反馈中。[Android 官方配对说明](https://developer.android.com/tools/adb#wireless)

索尼 BRAVIA 等电视如果只提供「无线调试」，请按上面的配对步骤连接，使用页面显示的端口。TCL / 雷鸟如果找不到配对码入口，请查看[特殊机型说明](#特殊机型说明)。投屏码不能用于 ADB 配对。

### 4. 把这段话发给 Agent

替换电视型号和地址；没有配对码时删掉配对相关的两行。

```text
请帮我在电视上安装「学后看」。
电视品牌和完整型号：<填写>
电视 IP 或连接地址：<填写，有端口请一起填写>
无线配对地址：<填写>
临时配对码：<填写>

请先阅读并按以下手册操作：
https://github.com/scfido/LearnThenWatch/blob/main/docs/DEPLOYMENT-AGENT.md

从 scfido/LearnThenWatch 的最新正式 Release 下载学后看 APK，
完成连接、校验、安装和启动，保留电视上的其他应用、数据和无障碍服务。
需要我在电视上允许连接时，请明确告诉我。
家长密码由我在电视上输入，装好后帮我确认「学后看 · 观看管控」是否已开启。
遇到问题请先排查，再用简单的话告诉我需要做什么。
```

## 方式二：手动 U 盘安装

这种方式不需要 Agent，也不需要开启 ADB。

1. 在电脑上打开[最新版本下载页](https://github.com/scfido/LearnThenWatch/releases/latest)，展开 **Assets / 资源**。
2. 下载以 `.apk` 结尾的文件，例如 `learn-then-watch-版本号.apk`；不要下载 `Source code` 压缩包。
3. 把 APK 复制到电视能够识别的 U 盘根目录，不要放在压缩包里。
4. 把 U 盘插到电视，打开电视自带的「文件管理」「U 盘」或「外接设备」，找到这个 APK。
5. 选中 APK 安装。若提示「未知来源」或「允许安装未知应用」，按提示允许当前文件管理工具安装，再返回继续。
6. 安装完成后打开「学后看」，按[首次打开](#首次打开)完成设置。

升级也可下载新版 APK 后直接安装，使用同一官方签名时会保留学习记录和配置。遇到签名冲突先停止并反馈，不要通过卸载或清除数据解决。

## 特殊机型说明

菜单位置会随型号和固件版本变化。找不到对应入口时，把完整型号、Android 版本和当前页面提示交给 Agent 查询。

| 机型或情况 | 操作方法 |
| --- | --- |
| **TCL / 雷鸟：有无线调试，没有配对码入口** | Q10M、鹤 6 Ultra 等部分固件需要先通过 USB 连接电脑并授权。请 Agent 按完整型号确认调试接口和数据线，再进行连接；也可选择 U 盘安装 |
| **TCL / 雷鸟：ADB 安装失败** | 改用 U 盘或电视已有的文件管理器。电视支持「多屏互动」推送时，也可通过该入口安装，并在电视提示中选择「同意」 |
| **TCL / 雷鸟：找不到无障碍设置** | 请 Agent 检查能否通过已授权的 ADB 开启观看管控。若系统不允许授权，可先使用英语学习功能 |
| **极米 H3 / Z7X、当贝 F5 等投影仪：找不到 ADB 开关** | 优先用 U 盘安装。安装后从应用列表打开学后看，再按提示设置观看管控 |
| **海信 / Vidda** | 在「关于本机」确认 Android 版本，并检查是否允许安装 APK；系统只允许使用自带应用商店时，请先向厂商确认安装方式 |
| **老乐视、荣耀智慧屏、老康佳等：找不到调试入口** | 先检查 Android 版本和 U 盘安装功能。Android 低于 8.0 或系统不支持 APK 安装时，无法安装学后看 |

## 首次打开

1. 设置并确认四位数字的家长密码，请妥善保存。
2. 在「家长配置」选择 KET 或 PET 阶段、学习起点及每天的学习量和观看时长。
3. 如果需要管理观看时间，按提示进入电视「无障碍」设置，开启「学后看 · 观看管控」。
4. 返回应用「监控检查」，确认服务已连接，再让孩子开始学习。

仅进行英语学习时，可以先使用课程；需要观看时间管理时再完成相应授权。

部分 Android 13 及以上系统在从文件安装后，会提示无障碍属于「受限制的设置」。确认安装的是官方学后看后，到「设置 → 应用 → 学后看 → 更多」查找「允许受限制的设置」，再返回开启无障碍；电视菜单可能不同，没有入口时请 Agent 按型号核对。[Google 官方说明](https://support.google.com/android/answer/12623953?hl=zh-Hans)

需要开机或待机后自动恢复管控时，请使用 1.5.5 或更新版本，让 Agent 按[部署手册](DEPLOYMENT-AGENT.md#可选开机与待机后的后台恢复)配置。恢复在后台进行，保留电视当前画面；需要额外授权，效果以这台电视的实际检查为准。U 盘安装后仍可手动开启无障碍服务，需要自动恢复时再让 Agent 协助。

## 常见问题

| 遇到的情况 | 可以先这样处理 |
| --- | --- |
| 找不到 ADB 开关 | 把电视完整型号和系统版本告诉 Agent，按型号查找；也可以选择 U 盘安装 |
| 配对成功，但仍连不上 | 检查是否把配对端口当成连接端口；重新提供无线调试主页面的连接地址 |
| 电脑找不到电视 | 确认连接同一家庭网络，避免访客 Wi-Fi；检查电视上的调试开关和授权弹窗 |
| U 盘没有显示 APK | 用系统文件管理查看，确认文件以 `.apk` 结尾且未压缩；检查 U 盘是否能被电视识别 |
| 提示无法解析或无法安装 | 重新下载完整 APK，并核对电视系统是否达到 Android 8.0；如系统限制第三方应用安装，按厂商允许的方式处理 |
| 电视仅支持自带应用商店 | 先确认该型号是否支持 Android APK；更换连接方式不一定能解决系统限制 |
| TCL / 雷鸟提示安装校验失败，创维提示禁止安装 | 保留报错原文，先检查电视的安装授权，或改用 U 盘和已有文件管理器；交给 Agent 按[特殊安装排查](DEPLOYMENT-AGENT.md#特殊安装排查)处理 |
| 无障碍开关是灰色，提示受限制的设置 | 按上方「首次打开」处理应用的受限设置；没有入口时按完整型号核对 |
| 安装后没有管理观看时间 | 进入「监控检查」，按提示完成家长密码和无障碍授权；兼容范围见[兼容性说明](VALIDATION.md) |
| 待机后管控失效 | 先重新开启「学后看 · 观看管控」；支持后台恢复的版本可让 Agent 配置额外授权，并在这台电视上验证 |

仍有问题，可到[问题反馈](https://github.com/scfido/LearnThenWatch/issues)提供电视品牌、完整型号、Android 版本、固件版本、学后看版本、安装方式和报错内容，并说明是不能安装、不能学习，还是观看管控未连接。不要附 PIN、配对码或设备地址。安装完成后，可以关闭 ADB 调试。

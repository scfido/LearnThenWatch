## 公众号宣传稿
- 草稿放 WorkBuddy 会话空间（仓库外），定稿归档到 `docs/blogs/<日期>-<主题>/` 并通过 git 管理，索引见 `docs/blogs/README.md`。标准三件套：md 源稿 + 可直接粘贴到公众号后台的 HTML（图片 base64 内嵌）+ 900×383 封面 PNG。`make_images.py` / `make_html.py` 使用相对路径，改文案后重跑。
- 封面视觉体系（与首篇保持一致）：米黄 `#F5EAD3` 底、深绿 `#1F5B45`、暖橙 `#E7A23B`、雾蓝 `#8AB8C6`，扁平插画、电视机 + 品牌小鸟，2.35:1。
- 写作风格用户尚未定型：首篇（2026-11-09）AI 味偏重，用户要求不沿用。以当轮指令为准，倾向平实、具体、少套话，不套「钩子—转折—升华」结构。事实一律以 `CHANGELOG.md` / `docs/VALIDATION.md` 为准，已知限制照直说，不写「彻底解决 / 全面适配」。
- 公众号正文外链不可点，GitHub 地址用纯文本；不写诱导分享话术；第三方课程内容不宣称自有版权。
- 品牌口径（用户 2026-11-16 选定）：应用名不改，对外统一用「学后看 · 电视英语」，并带固定句「先学一轮英语，再看一会儿电视」。系统无障碍服务名「学后看 · 观看管控」是电视设置里的真实名称，宣传稿原样保留、不跟着改；README / INSTALL / CHANGELOG 等仓库文档与应用 label 由用户自行调整。首篇（2026-11-09）已发布，归档稿保持发布原样，不追溯修改。

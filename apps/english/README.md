# 看电视学英语

面向已有英语基础的孩子的离线 Android TV 应用：**先学习，再换取一轮观看时间**。包名保持 `local.mytv.english`，目前管理云视听小电视 `com.xiaodianshi.tv.yst`。

## 学习与观看

- 默认每轮完成 5 项主任务，集中订正错题后获得 10 分钟观看时间；每日最多实际观看 60 分钟。
- 首次没有观看余额。只有一轮余额，已有余额时完成额外学习不叠加时间；每日剩余额度不足 10 分钟时，仅奖励剩余额度。
- 仅确认目标播放页面在前台、屏幕开启、有媒体音频活动时扣时。暂停、浏览列表、待机、学习期间不扣时；检测采样约一秒，服务断开时间不补扣。
- 同日重启恢复余额；按电视本地自然日结算，跨日旧余额清零。达到日上限仍可以学习。
- 学习首页和播放器拦截页共用同一会话。主任务、选项顺序、新词认识、首次答案和订正状态都自动保存。
- 答错先讲解，主任务结束后订正；订正连续两次错误会提供带答案的理解确认。订正完成可兑换，首次答错仍记录为需复习。
- KET → PET 主题课程，每轮最多引入 2 个新词，每日默认最多 5 个。复习间隔为 1、3、7、14、30 天；到期独立正确才推进掌握度，提前练习不会推迟复习日期。

奶油白、蓝绿和暖黄色的界面包含首页、探险地图、词汇回看、学习记录和家长配置。全部操作支持方向键、确认键和返回键，焦点有高亮描边和轻微位移反馈。

## 1.1.0 儿童界面与连续学习

- 学习、错题讲解、订正、完成页与词汇回看使用固定左右布局，全部内容在一屏显示，字体随可用空间调整，不依赖滚动或省略号。
- 进入本轮直接选答案，不再经过单独的新词确认页；需要帮助时选择“不认识”，集中查看释义和例句，并保留真实首次错误记录。
- 答对后约 0.6 秒自动进入下一题；答错只保留一次“记住了”操作。主任务结束后直接进入订正，完成后确认“继续观看”。
- 听音题自动播放题目音频，其他题型遵从家长的自动发音设置；静音或播放失败时可明确切换为文字练习。
- 新增原创探险伙伴的漂浮、眨眼、答对反馈、卡片入场和完成彩纸动画。退出、切后台会取消翻题回调并释放音频，返回时读取已保存的任务。
- 焦点边框向内绘制，切换状态保留文字内边距，不再向外放大按钮。首页和学习页精简说明文字，保留必要的题意、额度与异常信息。

交互参考百词斩[官方介绍](https://apps.apple.com/cn/app/%E7%99%BE%E8%AF%8D%E6%96%A9-%E8%83%8C%E5%8D%95%E8%AF%8D-%E5%AD%A6%E8%8B%B1%E8%AF%AD%E6%97%A5%E8%AF%AD%E9%9F%A9%E8%AF%AD%E6%B3%95%E8%AF%AD/id557545298)中将释义、发音和例句集中呈现的方式，并适配电视遥控器。

## 1.2.0 遥控器操作

| 按键 | 页面浏览 | 学习与词卡 |
| --- | --- | --- |
| 上 / 下 | 在整张卡片、整行设置间移动，列表自动滚动 | 选择答案，末项下方可选“不认识” |
| 左 | 从内容区进入侧栏 | 直接重听，保留当前答案焦点 |
| 右 | 从侧栏回到刚才的内容焦点 | 保持当前选择 |
| 确认 | 打开整张卡片，或切换整行设置的值 | 作答；词卡内也可确认重听 |
| 返回 | 按实际入口逐页回退，根页退出应用 | 保存任务并回到进入学习的页面 |

首页学习卡、观看余额卡、地图单元、单词条目和家长设置均直接确认操作，不再嵌套“查看”等按钮。普通页面、词卡和学习页不显示返回按钮；清除数据仍保留明确的取消/确认选择。

返回路径会保留焦点和滚动位置，例如“地图 → 单元 → 词卡”和“记录 → 待复习 → 词卡”分别返回原列表；家长记录、来源、授权说明、起点选择和演示也保留各自的入口。取消 PIN 会退回入口；从后台回来访问家长页面需重新验证，取消验证不会陷入返回循环。

学习中的左键重听不需要把焦点移到播放按钮。答对后自动翻题期间按左键，会先听完发音再继续。观看中弹出的学习页按返回键会退出观看，未完成任务仍保留。

## 首次设置

1. 打开「看电视学英语」，选择首次家长设置，设置并再次确认四位数字 PIN。
2. 在家长配置调整每轮任务、兑换分钟、每日上限、KET/PET 阶段、学习起点、每日新词、发音音量、自动发音和中文辅助提示。
3. 在电视无障碍设置开启「英语学习换时管控」。小米电视入口优先打开小米系统设置主页，避免部分固件标准无障碍页面异常。
4. 返回应用确认状态显示“正在生效”，完成一轮学习后选择“继续观看”。

未设置 PIN 或无障碍未连接时，会明确显示“未生效”。无障碍权限只用于本机识别播放器、显示学习覆盖层和请求临时音频焦点。应用无网络权限。

进入配置、更改 PIN、关闭管控和清除数据有 PIN 保护。PIN 使用随机盐与 PBKDF2 保存，连续验证错误会短暂锁定；没有云端找回。请家长妥善保存 PIN。

任务数与兑换时长在下一轮生效，日上限下调立即裁剪余额。恢复默认配置保留 PIN 和学习记录；清除学习与观看记录需要确认并再次验证 PIN。演示模式不记录学习或发奖。

## 课程内容

KET/PET 课程、发音及来源说明全部随安装包离线提供，覆盖范围、内容类型、生成方法与审核状态见 [CONTENT.md](CONTENT.md)。课程进度代表本应用的词汇学习进度。

自然例句使用原创内容或保留逐条来源的许可语料；只有词义线索的条目仅用于认词和听辨。音频为预置机器合成发音，不依赖电视英语 TTS。听辨必须成功播放音频后才能作答；播放失败可重试，或明确切换为同知识点的文字练习，不会把播放失败当成答对。

内容通过自动检查和抽查，完整人工教学审校仍需后续完成，具体状态与覆盖清单随内容包保存。

## 构建与安装

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0。默认 SDK 位于 `%LOCALAPPDATA%\Android\Sdk`。

```powershell
.\build.ps1 -App english
adb -s 192.168.1.132:5555 install -r .\apps\english\build\englishquiz.apk
adb -s 192.168.1.132:5555 shell am start -n local.mytv.english/.SettingsActivity
```

构建沿用根目录 `build/local-signing.jks`，请保留密钥以支持覆盖升级。旧版的提醒开关保留；原 `elapsed/due` 不折算观看余额，首次升级从零余额开始。其他应用独立安装、升级与卸载。

## 管控边界

这是普通电视应用，保留 Home 和系统设置，可通过系统关闭无障碍或卸载应用。家长 PIN 保护应用内配置，不提供设备级锁定。部分电视管家可能需要允许后台运行。

播放检测依赖前台播放页面与媒体音频流，不读取视频本身进度。没有音频流的视频不扣时；其他后台音频可能影响检测，播放器更新后需重新验证。音频焦点是暂停请求，实际暂停和恢复由播放器决定，应用会显示请求状态。

移除前请在家长配置关闭管控，或在系统无障碍设置停用服务，再卸载；卸载会删除本机学习数据。

实体待机验收未通过，属于当前固件限制：电源待机触发 `PowerManagerService killAllThirdApp`，强停英语应用并从 `enabled_accessibility_services` 移除它；唤醒后只保留小爱同学。已在应用监控页和 README 明确提示需重新开启授权，普通应用无法自行恢复系统撤销的权限。完整待机测试会报告失败；`--skip-standby` 明确排除此项，不代表待机恢复通过。

完整重启后的后台恢复验收通过：`boot_count` 从 540 增至 541。重开网络调试并重新连接后，在运行复测或手动启动英语界面之前，读到系统已自动连接 `LearningService`（PID 2667，`connected=true`，已有 1,849 次采样），英语无障碍授权保留，状态为等待播放；前台仍是系统桌面，`start_3rd_app` 仍为空。正式余额 600,000 ms、当日使用 0 ms 与重启前一致，未补扣停机时间。完整重启会关闭当前固件的 ADB 5555 端口，重新开启调试只用于读取验收状态。

重启后再次通过 34 项真实监控联动断言（显式排除实体待机），覆盖实际播放耗尽、暂停恢复、返回/Home 后重进及系统重连。复测工具使用视频卡片的真实无障碍节点适配不同首页布局；播放器推广页中断学习时给出明确失败信息，避免测试回调因空引用崩溃。测试清理先离开播放器回到桌面，再恢复正式服务，避免清理期间扣除正式观看余额。
